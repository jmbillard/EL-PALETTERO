ELPALLETERO

O painel abaixo é o mesmo código da extensão, ligado a uma composição de mentira. Selecione um layer e clique numa cor.

El PALLETERO ≡

Experimente

clique

Aplica a cor nos layers selecionados. Com propriedades de cor selecionadas, muda só elas; senão usa um Fill (e reaproveita o último).

botão dir.

Edita. O editor nasce da própria amostra e volta para ela ao confirmar. Cole qualquer #hex, rgb ou hsb.

arrastar

Reordena as cores. Os vizinhos abrem espaço.

Alt

Modo excluir. As amostras tremem; clique para remover. Tudo tem desfazer (Ctrl+Z).

Ctrl

Copia o valor no formato escolhido (HEX, RGB ou HSB).

Shift

O conta-gotas vira projeto inteiro enquanto a tecla estiver pressionada. Passe o mouse nele: o ícone já mostra o que vai fazer.

nomes

Cada cor ganha um nome (menta, tijolo, céu…) que acompanha a cor no editor até você digitar o seu. A ✦ devolve o automático.

conta-gotas

Entende a seleção: com praia_entardecer.jpg selecionado ele vira imagem e extrai as cores do frame; com shapes, captura as cores dos layers; sem nada, usa o frame da comp.

presets

Biblioteca de presets numa pasta que você escolhe (pode ser da equipe). Clique substitui, Shift adiciona, ★ vira o padrão.

projeto

Troque de projeto no topo: cada .aep guarda a própria paleta num grupo de metadados El PALLETERO.

formato

Faixa, coluna ou grade: o painel se reorganiza sozinho. Arraste o canto para redimensionar.
